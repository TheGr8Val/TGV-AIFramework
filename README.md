## 📖 About

**TGV AI Framework** is a single-page interactive reference for anyone who needs to decide which type of AI to use on a project — before they've written a single line of code.

It's not academic. It's a decision-making tool: walk a tree, read the tradeoffs, pick your stack, and ship.

| What | Detail |
|---|---|
| 🌐 **Format** | Single-page HTML — no install, no dependencies |
| 🎯 **Audience** | Engineers, analysts, builders — anyone starting an AI project |
| 🔮 **Scope** | ML, LLM, Generative AI, and Agentic AI |
| 🎨 **Design** | Matches [thegr8val.github.io](https://thegr8val.github.io) — Space Mono + Syne, dark theme |

---

## 🤔 The 4 Types — TL;DR

```
  Output is a label or score?          → ML
  Output is text, language, or code?  → LLM
  Output is something new / creative? → GenAI
  Task needs actions across steps?    → Agentic

  When in doubt: start with LLM. Add complexity only when it earns its keep.
```
